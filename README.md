# Valentines26

This is a simple interactive Valentine's Day letter web app, ready for deployment on GitHub Pages.

## How to deploy

1. Push all files to your GitHub repository (e.g., `valentines26`).
2. Go to your repository settings on GitHub.
3. Under "Pages", set the source branch to `main` (or `master`) and the folder to `/root`.
4. Your site will be available at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- All assets are referenced with relative paths for GitHub Pages compatibility.
- Place your music file as `music.mp3` in the root directory.
- No build step is required; just static files.
